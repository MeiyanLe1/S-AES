# S-AES 加解密实验程序 · 开发手册（接口文档）

> 面向二次开发者 / 评阅者。描述模块划分与对外接口。所有对外符号均来自各模块 `__all__`。

## 1. 架构与模块划分

```
s_aes/
├── core.py     算法核心（无 GUI 依赖，仅标准库）
├── modes.py    工作模式：分组、填充、字符串、CBC、篡改分析
├── multi.py    多重加密（双/三重）与中间相遇攻击
├── selftest.py 内置自测（GUI 按钮与 --selftest 共用）
└── gui/        PyQt5 界面层（page_base / theme / widgets / 各 tab / main_window）
```

设计约定：

1. **对外接口一律用 `int` 表示 16 bit 数据**，避免字节序歧义。
2. 内部把 16 bit 拆成 4 个半字节 `(s00, s10, s01, s11)`，状态矩阵按**列主序**填充（第一列占高 8 位）。
3. 算法层与界面层彻底分离：页面只做输入校验与渲染；重复控件抽成 `gui/widgets.py` 的可复用类。

## 2. `core.py` —— 算法核心

### 2.1 常量

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `S_BOX` | `tuple[int, ...]` | 16 项 S 盒（半字节代替盒），4×4 |
| `INV_S_BOX` | `tuple[int, ...]` | 逆 S 盒，满足 `INV_S_BOX[S_BOX[x]] == x` |
| `MIX_MATRIX` | `tuple[tuple[int,int], ...]` | 列混淆矩阵 `[[1,4],[4,1]]`，GF(2⁴) 上 |
| `INV_MIX_MATRIX` | `tuple[tuple[int,int], ...]` | 逆列混淆矩阵 `[[9,2],[2,9]]` |
| `ValidationError` | 异常类 | 输入不合法 / 长度不符时抛出，GUI 层统一捕获 |

### 2.2 密钥与单分组加解密

```python
expand_key(key: int) -> tuple[int, int, int]
```
扩展 16 bit 密钥，返回 `(K0, K1, K2)`。内部用 `lru_cache` 缓存，长文本每个分组不必重复扩展。

```python
encrypt_block(plaintext: int, key: int) -> int
decrypt_block(ciphertext: int, key: int) -> int
```
单分组加 / 解密，返回 16 bit 整数。`plaintext`/`ciphertext` 均须 0~0xFFFF，否则抛 `ValidationError`。

```python
encrypt_block_debug(plaintext: int, key: int) -> dict
decrypt_block_debug(ciphertext: int, key: int) -> dict
```
加 / 解密并记录每个变换后的中间状态，供第 2 关交叉测试逐项比对。
返回字典含 `plaintext/key/round_keys/steps/ciphertext`（加密）或 `ciphertext/key/round_keys/steps/plaintext`（解密）；`steps` 为 `[{label, value}, ...]` 列表。

### 2.3 GF(2⁴) 与位/半字节工具

```python
gf_mul(left: int, right: int) -> int
```
GF(2⁴) 乘法，模多项式 `x⁴ + x + 1`（俄罗斯农民乘法，带 `lru_cache`）。

```python
get_bit(value: int, bit_index: int, bit_width: int = 16) -> int
format_binary(value: int, bit_width: int = 16, group_size: int = 4) -> str
format_hex(value: int, bit_width: int = 16) -> str
```
取某一位 / 格式化为带分组的二进制串 / 固定宽度大写十六进制串。

```python
parse_hex_value(text: str, bit_width: int = 16) -> int
parse_binary_value(text: str, bit_width: int = 16) -> int
```
解析十六进制 / 二进制输入（容忍空格、`0x` 前缀、大小写），越界抛 `ValidationError`。

> 内部辅助（非 `__all__`，但接口稳定）：`split_nibbles` / `join_nibbles`、`add_round_key`、`sub_nibbles` / `inv_sub_nibbles`、`shift_rows` / `inv_shift_rows`、`mix_columns` / `inv_mix_columns`、`xtime`、`_rot_word`、`_sub_word`、`parse_flexible`。

## 3. `modes.py` —— 工作模式与字符串扩展

> 分组大小 `BLOCK_SIZE = 2`（字节）。字符串按 2 字节分组，UTF-8 编码。

### 3.1 分组与填充

```python
pad(data: bytes) -> bytes
```
PKCS#7 变体填充：缺 1 字节补 `0x01`，缺 2 字节（整除）补一整组 `0x02 0x02`。

```python
unpad(data: bytes) -> bytes
```
去除填充；填充不合法（如密文被篡改）抛 `ValidationError`。

```python
bytes_to_blocks(data: bytes) -> list[int]
blocks_to_bytes(blocks: Sequence[int]) -> bytes
xor_bytes(left: bytes, right: bytes) -> bytes
```
2 字节切分组（大端）/ 还原 / 等长逐字节异或（CBC 链式反馈用）。

```python
encrypt_bytes(data: bytes, key: int) -> bytes
decrypt_bytes(data: bytes, key: int) -> bytes
```
对长度恰为 2 的整数倍的数据逐组 ECB 加 / 解密（不填充）。

### 3.2 字符串加解密（第 3 关）

```python
encrypt_ascii(text: str, key: int) -> dict
```
加密字符串，返回 `{"raw","padded","groups","cipher_bytes","cipher_hex","cipher_display","padding_length"}`；`groups` 为每组 `{index, plain_block, cipher_block}`；`cipher_display` 为非可打印字节用 `·` 占位。

```python
decrypt_ascii(cipher_bytes: bytes, key: int) -> dict
```
解密字符串密文，返回 `{"padded_plain","plain_bytes","text","padding_valid","padding_error","groups"}`；`padding_valid=False` 时 `padding_error` 给出原因。

### 3.3 CBC 模式（第 5 关）

```python
encrypt_cbc(plaintext: bytes, key: int, iv: int, use_padding: bool = True) -> dict
```
CBC 加密：`C_i = E_K(P_i ⊕ C_{i-1})`，`C_0` 的前一组即 IV。`use_padding=False` 时要求明文长度已为偶数。
返回 `{"iv","padded","padding_length","plain_groups","cipher_groups","cipher_bytes","detail"}`。

```python
decrypt_cbc(cipher_groups: Sequence[int], key: int, iv: int, strip_padding: bool = True) -> dict
```
CBC 解密：`P_i = D_K(C_i) ⊕ C_{i-1}`。`strip_padding=False` 保留填充字节，用于篡改演示。

```python
tamper_analysis(cipher_groups, key, iv, group_index, new_value) -> dict
```
篡改指定密文分组后重新解密并分析错误传播。返回 `{"group_index","original_groups","tampered_groups","original_plain","tampered_plain","original_groups_plain","tampered_groups_plain","diff_positions","delta","explanation"}`；`explanation` 为文字说明（被改组整组乱码、下一分组仅翻转位、其余不受影响）。

### 3.4 展示辅助

```python
bytes_to_display(data: bytes, placeholder: str = "·") -> str
decode_text(data: bytes) -> str
```
可打印字符 + 占位符渲染 / UTF-8 解码（非法序列用替代字符，保证界面不抛异常）。

## 4. `multi.py` —— 多重加密与中间相遇攻击

> 32 bit 密钥约定：`Key = K1 ‖ K2`（高 16 位 K1，低 16 位 K2）。

```python
split_key_32(key32: int) -> tuple[int, int]
```
把 32 bit 密钥拆成 `(K1, K2)`。

```python
double_encrypt(plaintext: int, key32: int) -> int
double_decrypt(ciphertext: int, key32: int) -> int
```
双重加 / 解密：`C = E_K2(E_K1(P))` / `P = D_K1(D_K2(C))`。

```python
triple_encrypt(plaintext: int, key32: int) -> int
triple_decrypt(ciphertext: int, key32: int) -> int
```
三重加 / 解密（EDE，K3=K1）：`C = E_K1(D_K2(E_K1(P)))`；`K1==K2` 时退化为单次 S-AES。

```python
meet_in_the_middle(
    pairs: Sequence[tuple[int, int]],
    progress_callback: Callable[[int, int], None] | None = None,
    cancel_check: Callable[[], bool] | None = None,
) -> dict
```
对双重加密发起中间相遇攻击。
- `pairs`：`[(明文, 密文), ...]`，至少一组；第一组用于建表匹配，其余用于验证。
- `progress_callback`：可选，参数 `(已完成步数, 总步数)`，用于进度条。
- `cancel_check`：可选，返回 `True` 时提前结束（GUI 关闭窗口用）。
- 返回 `{"candidates":[(K1,K2),...], "elapsed", "table_entries", "middle_hits", "cancelled"}`；候选密钥已用全部明密文对复核。

## 5. `selftest.py` —— 内置自测

```python
run_self_check(include_attack: bool = True) -> list[dict]
```
执行全部自测项，返回 `[{"name":str, "ok":bool, "detail":str}, ...]`。
覆盖：密钥扩展、附录 D 中间算例、已知向量、200 组随机往返、字符串往返、CBC 往返、篡改传播、三重加密、中间相遇攻击。
GUI 顶部「算法自测」按钮与 `python main.py --selftest` 共用此函数。

## 6. 调用示例

```python
from s_aes.core import encrypt_block, decrypt_block, expand_key
from s_aes.modes import encrypt_ascii, decrypt_ascii, encrypt_cbc, decrypt_cbc
from s_aes.multi import double_encrypt, double_decrypt, meet_in_the_middle

# 单分组
c = encrypt_block(0x6F6B, 0xA73B)      # -> 0x0738
p = decrypt_block(c, 0xA73B)           # -> 0x6F6B

# 字符串（支持中文）
rep = encrypt_ascii("信息安全导论", 0x2D55)
back = decrypt_ascii(rep["cipher_bytes"], 0x2D55)   # back["text"] == "信息安全导论"

# CBC
r = encrypt_cbc(b"hello", 0x2D55, 0x5A5A)
d = decrypt_cbc(r["cipher_groups"], 0x2D55, 0x5A5A)

# 多重加密 + 中间相遇攻击
key32 = 0x1F2E_3D4C
ct = double_encrypt(0x1234, key32)
attack = meet_in_the_middle([(0x1234, ct)])
# attack["candidates"] 应包含 (0x1F2E, 0x3D4C)
```
